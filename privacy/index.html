Privacy Policy, AIOS Escalano

Last updated: 17 October 2026

AIOS Escalano is an internal tool of Popcorn Brains (Senior VOF, Niel, Belgium). It is used only by Popcorn Brains to manage its own YouTube channel, ESCALANO. It is not offered to the public.

What it does

The tool uses the YouTube API Services (YouTube Data API v3 and YouTube Analytics API) to manage the ESCALANO channel: channel settings, uploading and editing videos, playlists and thumbnails, and reading comments and statistics.

By using the tool, the channel owner agrees to the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.

What data it uses and stores

  • It only accesses the data of the YouTube channel that authorized it.
  • On Popcorn Brains' own computer it stores the authorization token, a log of the changes it made, and which videos carry an AI label.
  • It does not store comments, commenter details or statistics. It only shows them to the channel owner.
  • It does not share or sell data, shows no ads, and this page sets no cookies.

Revoking access

Access can be revoked at any time in the Google account's security settings. After a revocation, the locally stored data is deleted within 7 days.
